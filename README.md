# 🥽 VR Box · Quest — игра + сервер

Один Node.js-сервер делает всё сразу:
- раздаёт игру (`public/index.html`);
- аккаунты и облачные сохранения (`/api/register`, `/api/login`, `/api/me`, `/api/save`);
- онлайн-комнаты «server #1 … #4» (WebSocket): позиции игроков, ники, предметы в руках;
- голосовой чат по радиусу (по умолчанию 14 м).

## Запуск на компьютере
```
npm install
npm start
```
Открой http://localhost:3000.

Камера в браузере работает только по **https** (или на localhost). Для телефона нужен
https-адрес: либо выложи на Render (ниже), либо пробрось туннелем, например
`npx cloudflared tunnel --url http://localhost:3000`, и открой выданную ссылку.

## Выкладка на Render (бесплатно)
1. Залей папку в репозиторий на GitHub.
2. Render → New → **Blueprint** (подхватит `render.yaml`) или New → Web Service:
   Build `npm install`, Start `npm start`.
3. Открой выданный адрес `https://…onrender.com` на телефоне — игра сама подключится к серверу.

Бесплатный Render засыпает без активности (первый заход до минуты) и стирает файлы
при перезапуске. Чтобы аккаунты не пропадали, подключи Persistent Disk и задай
`DATA_DIR=/путь/к/диску`.

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | 3000 | порт |
| `DATA_DIR` | `./data` | где лежит `users.json` |
| `MAX_PLAYERS` | 30 | игроков в одной комнате (до 250) |
| `VOICE_RADIUS` | 14 | дальность голоса, метры |

## Игра на отдельном хосте
Если `index.html` лежит отдельно, укажи сервер в адресе: `https://твой-сайт/?server=https://vr-box-quest.onrender.com`.

## Протокол WebSocket (для справки)
- клиент → `{t:'join',room,token}`, затем `{t:'pos',x,y,z,r,h,m}` и бинарные куски голоса (Int16 PCM, 8 кГц);
- сервер → `{t:'hello',id}`, `{t:'state',n,p:[…]}`, `{t:'full'|'kick'|'auth'}` и бинарный голос `[id][PCM]`.

Пароли хранятся только в виде scrypt-хэша, токены — в виде sha256.
